# Screenshot slots

Real screenshots are intentionally not fabricated. After installing and previewing the theme, replace this file or add captures using these stable paths:

- `desktop.png` — full desktop with the SmokeyEmber wallpaper and omarchy-shell bar.
- `launcher.png` — Omarchy launcher/menu surface.
- `terminal-nvim.png` — terminal and Neovim palette together.

The main README already references these expected names so they can be added without reorganizing the repository.
